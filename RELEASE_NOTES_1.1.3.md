# Netbridge 1.1.3

- Исправлена ложная ошибка «Не найдено активное сетевое подключение» для активных туннельных маршрутов macOS без шлюза.
- Если подходящий маршрут IPv4 не найден, проверяется маршрут IPv6.
- Для каждого вызова определения маршрута установлен таймаут 3 секунды.
- Для маршрута без шлюза подбор выполняется без чтения и записи сетевого кеша стратегий. Обычные подключения сохраняют прежний формат ключа кеша.
- Сохранены оформление, новый логотип и иконка приложения из версии 1.1.2.

Наличие маршрута не гарантирует доступность YouTube или совместимость с VPN: это проверяется отдельно при подборе стратегий. Исправление не меняет PF-правила и движок обхода.

Требуется macOS 14 или новее. Сборки не имеют подписи Developer ID и нотариализации Apple.
