# Netbridge 1.1.4

- Добавлена проверка совместимости маршрута перед автоподбором YouTube: встроенный ZapretMac требует IPv4, шлюз и его MAC-адрес. Маршрут через VPN-туннель не поддерживается.
- При конфликте приложение предлагает отключить VPN/туннелирование до загрузки компонентов, записи конфигов и запроса прав администратора.
- Маршрут проверяется повторно после подтверждения macOS, до изменения системного сервиса.
- Ошибка установки движка сохраняется отдельно и больше не скрывается за сообщением о восстановлении настроек.
- Netbridge не отключает VPN и не меняет его маршруты автоматически. Поддержка туннельных маршрутов для определения кеша в 1.1.3 не означала совместимости самого движка; это ограничение теперь проверяется явно.

Требуется macOS 14 или новее. Сборки не имеют подписи Developer ID и нотариализации Apple.
