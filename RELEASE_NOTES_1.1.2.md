# Netbridge 1.1.2

- Убраны подпись «Интернет без границ», хлебные крошки в верхней панели и блок «Мой Mac».
- Добавлен предоставленный пользователем логотип с прозрачным фоном вместо глобуса.
- При наведении на логотип проигрывается короткий подскок. Системная настройка «Уменьшение движения» отключает анимацию.
- Иконка Electron заменена новым логотипом в Dock и ресурсах приложения macOS.
- Отображаемая в интерфейсе версия берётся из метаданных приложения.

Требуется macOS 14 или новее. Сборки не имеют подписи Developer ID и нотариализации Apple. Сервисная логика не изменена относительно 1.1.1.
